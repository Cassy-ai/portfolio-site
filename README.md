# Portfolio Site

A modern, responsive one-page portfolio showcasing services and tools.

## Features

- **Sticky Navigation** - Easy access to all sections
- **Hero Section** - Eye-catching introduction with call-to-action
- **Services Showcase** - Display your 4 key services with icons
- **Tools & Technologies** - Organized by category (Frontend, Backend, Tools & Platforms)
- **Contact Section** - Multiple ways to get in touch
- **Responsive Design** - Looks great on all devices
- **Modern Styling** - Clean, professional design with smooth animations

## Sections

### Header
- Logo and navigation links
- Sticky positioning for easy access

### Hero
- Headline and tagline
- Call-to-action button

### Services
- Grid layout with 4 service cards
- Icons, titles, and descriptions
- Hover effects

### Tools & Technologies
- Categorized tool lists
- Frontend, Backend, and Tools & Platforms
- Check mark indicators

### Contact
- Get in touch section
- Email, GitHub, and LinkedIn links

### Footer
- Copyright information

## Customization

Edit `index.html` to:
- Change your name and tagline
- Update services and descriptions
- Modify contact links

Edit `styles.css` to:
- Change color scheme (update CSS variables in `:root`)
- Adjust fonts and sizes
- Modify animations and transitions

### Color Variables
```css
--primary-color: #2563eb
--secondary-color: #1e40af
--text-color: #1f2937
--light-bg: #f9fafb
--white: #ffffff
--border-color: #e5e7eb
```

## Deployment

This portfolio can be deployed to:
- GitHub Pages
- Netlify
- Vercel
- Any static hosting service

Simply upload `index.html` and `styles.css` to your hosting provider.
